
# Linux Server Automation
#let's start

## Project Overview
This project automates basic Linux server monitoring
using Bash shell scripts.

## Features
- Displays hostname and current date
- Displays system uptime
- Monitors memory usage
- Checks filesystem disk usage
- Warns when disk usage reaches 80%

## Technologies
- Linux
- Bash Shell Scripting
- Git
- GitHub

## How to Run

Make scripts executable:

```bash
chmod +x system_info.sh disk_check.sh
```

Run system information:

```bash
./system_info.sh
```

Run disk monitoring:

```bash
./disk_check.sh
```
